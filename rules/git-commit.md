# Git Commit Scope

本项目提交消息使用 Conventional Commits，可按改动模块选择以下 scope：

- `extension`：VS Code 扩展宿主、webview 消息处理、命令注册
- `api`：粉笔接口请求、服务封装、数据转换
- `webview`：React 页面、路由、组件交互
- `style`：Less 样式、主题、视觉调整
- `canvas`：画板/批注绘制能力
- `question`：题目渲染、作答、解析展示
- `errors`：我的错题、错题练习、错题解析
- `settings`：插件配置、设置面板
- `docs`：文档、说明、变更日志
- `release`：版本号、发布相关文件

格式：`<type>(<scope>): <subject>`。
